# UST-Reserve

Aplicacion web para gestionar reservas de salas de estudio, pensada inicialmente para el contexto de la UST.

La idea del proyecto no es quedarse solo en ese uso: la estructura esta preparada para servir como base de una plantilla mas universal, de modo que pueda adaptarse a otras instituciones, espacios o flujos de reserva sin rehacer todo desde cero.

## Que hace

- Consulta y visualizacion de salas disponibles.
- Reserva y seguimiento de espacios.
- Acceso a informacion util del espacio antes de reservar.
- Estructura modular para crecer sin complicar el codigo.

## Tecnologias

- Nuxt 3
- Vue 3
- TypeScript
- Tailwind CSS
- Neon / PostgreSQL serverless

## Estado del proyecto

El proyecto sigue en evolucion. Algunas partes todavia estan en ajuste, tanto en funcionalidad como en presentacion, pero la base ya permite trabajar sobre una experiencia de reservas clara y reutilizable.

## Idea de uso

Aunque el nombre actual esta ligado a UST-Reserve, la intencion es que pueda convertirse en una plantilla generica para proyectos similares. Eso permite cambiar identidad visual, reglas de negocio y datos sin perder la base tecnica.
